# Registro de Decisiones Arquitectónicas (ADR)

Este archivo sirve como la "memoria compartida" del proyecto. Aquí se deben registrar todas las decisiones arquitectónicas importantes tomadas, justificando el porqué, para que cualquier agente pueda heredar el contexto en futuras sesiones.

*(Las nuevas decisiones se agregarán aquí abajo con el formato: Fecha - Título - Decisión y Justificación)*
