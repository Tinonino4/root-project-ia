# Root Project IA

Bienvenido al repositorio administrado con agentes de Inteligencia Artificial especialistas.

## Estructura del Proyecto

- `/backend`: Código backend (Java + Spring Boot). Incluye base de datos vía Flyway (`src/main/resources/db/migration`).
- `/frontend-nuxt`: Interfaz de usuario principal (Nuxt 3 / Vue 3 SSR)
- `/.gemini`: Archivos de configuración para agentes de Inteligencia Artificial (basados en los estándares).

*Para detalles operativos ver [AGENTS.md](AGENTS.md).*
